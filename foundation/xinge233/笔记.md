## Markdown 语法  

1.特殊符号前加\\实现正常输入  
2.换行:在前一行末尾加上两个空格  
3.超链接做法```[显示文字](目标 "悬停显示")```  
4.一些字体变化  
| 效果 | Markdown写法 | 说明 |
| ---- | ---- | ---- |
| **加粗** | `**文字**` | 最推荐，兼容性好；也可以用`__文字__` |
| *斜体* | `*文字*` | 也可以用`_文字_` |
| ***粗斜体*** | `***文字***` | 加粗+斜体组合 |
| ~~删除线~~ | `~~文字~~` | 划掉文字 |
| `行内等宽代码` | `` `文字` `` | 灰色背景，等宽字体 |
| <u>下划线</u> | `<u>文字</u>` | HTML标签，原生MD不支持 |
| <span style="color:red;">红色文字</span> | `<span style="color:red;">文字</span>` |  
>这份表格为ai生成
