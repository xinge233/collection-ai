### 4.浅拷贝、深拷贝

```python
a=[1,2[3,4]]

```

a=[1,2[3,4]]

### 5.列表推导式
 

基本结构`放进列表的元素 for 变量 in 可迭代对象 if 条件`  

```python
 # 普通写法
squares = []
for x in range(5):
    squares.append(x ** 2)
# [0, 1, 4, 9, 16]

# 推导式写法
squares = [x ** 2 for x in range(5)]
# [0, 1, 4, 9, 16]
```
>例子为ai生成

其中`放进列表的元素`
也可以if  
`[默认输出 if 条件 else 满足条件时输出 for 变量 可迭代对象]`
```
["偶" if x % 2 == 0 else "奇" for x in range(5)]
# ['偶', '奇', '偶', '奇', '偶']

[x if x > 0 else 0 for x in [-1, 2, -3, 4]]
# [0, 2, 0, 4]
```
>例子为ai生成

### 多重循环
`[最后输出的元素 for 在前面的元素先进行迭代 in 可迭代对象1 for 放在后面的元素再进行迭代 in 可迭代对象2 ...]`

```python
[(a1,a2,a3) for a1 in range(3) for a2 in range(3) for a3 in range(3)]#先固定 a1, 再固定a2,a3进行迭代,a3迭代好了a2迭代 1 次，再次进行a3的迭代.....a2迭代好了才到a1迭代 1 次.....
```
等价于
```python
result=[]
for a1 in range(3):
    for a2 in range(3):
        for a3 in range(3):
            result.append((a1,a2,a3))
            #这里append后面呢是个元组，append只能传一个元素，要将三个元素()变成一个元组
```
